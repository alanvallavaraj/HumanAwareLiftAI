# Revision report

## Scientific changes

Completed 5,184 event-recorded simulations with four controllers, 108 scenarios and twelve seeds. Reconstructed every restricted-wait aggregate from 7,076,364 events; verified matched arrivals in all 1,296 scenario-seed blocks. Added paired 2,000-replicate intervals for archived and new outcomes, general-group results and completion. Reported 783 historical replay discrepancies out of 3,888 comparisons without removing cases. One corrupt event file was replayed; all aggregate values matched.

The central finding is a priority-service trade-off. The historical 5.32% completed-trip waiting improvement is not a full-cohort improvement. Synthetic comfort, noise invariance, untested physical motion and interface claims have been removed from headline conclusions.

## Remaining publication decisions

The evidence is an exploratory rule-based simulation. The distance-only reference is distinct but not a reproduction of a published state-of-the-art controller. Physical sensing, weight/space capacity, motion and interaction validation remain outside scope. Historical executed-source provenance is incomplete. AEI fit remains uncertain because the requirement representation is fixed and no general reasoning method is introduced.

The data and code are archived on Zenodo, and the manuscript's dataset reference cites the archive's DOI.
